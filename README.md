# NetGeo - Searching the Seabed for Florida's Ice Age Societies

A responsive National Geographic editorial feature recreating the deep dive into Florida's submerged continental shelf and ancient American archaeology.

## Project Structure
- `index.html` - Editorial article markup & interactive modules
- `css/` - Custom editorial typography, light/dark themes, and responsive layout
- `js/` - Interactive audio narration player, cartographic explorer, lightbox & drawer controls
- `images/` - Editorial photography and curated story media

## Technologies
- HTML5 & CSS3
- Modern Vanilla JavaScript (ES6+)
- SVG Cartography & Custom Micro-Interactions
